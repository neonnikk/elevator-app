# Changelog — ТО Лифтов

## [3.0.0] — 2026-03

### Добавлено
- **JWT инвалидация**: поле `token_version` в таблице `users`. При смене пароля или блокировке все активные сессии пользователя мгновенно аннулируются
- **Исторические графики на дашборде**: навигация по прошлым месяцам, столбчатый график за последние 6 месяцев (выполнено / просрочено). Клик по столбцу переключает месяц
- **CHANGELOG.md** — этот файл

### Безопасность
- `invalidateTokens()` вызывается при: смене пароля пользователем, смене пароля администратором, блокировке, изменении роли
- После смены собственного пароля — автоматический разлогин с уведомлением

## [2.0.0] — 2026-03

### Добавлено
- **httpOnly cookie**: токен хранится в защищённой куке, недоступной JavaScript. `withCredentials: true` на всех запросах
- **WebSocket аутентификация**: `io.use()` проверяет токен при каждом подключении
- **Фильтр по исполнителю** на вкладке ТО: аватарки над списком карточек
- **Сортировка карточек** ТО: по статусу / названию / адресу / дню ТО
- **Сортировка колонок** в таблице Адресов
- **Экспорт**: детализация по подъездам и лифтам в Excel и PDF. Экспортируется текущий фильтр
- **Индикатор "обновлено X сек назад"** рядом с пульсирующей точкой
- **Поиск** на вкладке ТО по названию и адресу объекта
- **`building_audit_log`**: история изменений адресов (кто, когда, что изменил). UI в таблице Адресов
- **Дашборд**: обзорный экран с 4 счётчиками, прогресс-баром, просроченными и ближайшими сроками
- **Пагинация заявок**: серверная, 50 записей на страницу
- **Telegram по бригадам**: поле `telegram_chat_id` в профиле. Каждый исполнитель получает только свои объекты
- **React.lazy + Suspense**: страницы загружаются по требованию
- **`React.memo`** на `TaskCard`: нет лишних перерисовок при обновлении одной карточки
- **`utils/constants.js`**: единое место для `MONTHS_RU`, `STATUS_LABELS`, `STATUS_COLORS`
- **`.dockerignore`**: `node_modules` и `.git` не попадают в контекст сборки

### Исправлено
- `db` не был импортирован в `server.js` → `/health` падал с 500
- Race condition при одновременной постановке галочек → `db.transaction()`
- Экспорт игнорировал активные фильтры → передаётся `displayTasks`
- Текст пустого списка на ТО не различал "нет объектов" и "нет объектов по фильтру"

### Безопасность
- Блокировка мгновенная: `is_blocked` проверяется при **каждом** запросе
- `canAssignUsers` и `canDeleteBuildings` enforced на бэкенде
- Валидация ключей в `PUT /settings`: только whitelist

## [1.0.0] — 2026-02

### Добавлено
- Первичная структура: бэкенд Express + SQLite, фронтенд React + Vite
- Авторизация JWT, роли admin/user, 9 прав доступа
- Страницы: ТО, Адреса, Календарь, Заявки, Пользователи, Профиль
- Чекбоксы выполнения ТО с уровнями: здание / подъезд / лифт
- Реальное время через Socket.IO
- Telegram уведомления в 09:00 (cron)
- Экспорт в Excel и PDF
- PWA: Service Worker, manifest, иконки
- Почасовой бэкап через `sqlite3 .backup` с проверкой `PRAGMA integrity_check`
- Docker: три контейнера (backend, frontend/nginx, backup)
- nginx: gzip, Cache-Control для статики, проксирование API и WebSocket
